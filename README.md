TG6D (Twingate) is an experimental multi-model "council" system: a local FastAPI dashboard (`twingate_server.py`, served from `static/`) passes each conversation turn through several AI systems in rounds and records the transcripts and proposed builds in local log folders. To run it, start it with `python twingate_server.py` (it needs `fastapi` and `uvicorn`), open http://127.0.0.1:8000, and enter your own API keys for the services you want to use; they are saved only to `Twingate Core/twingate_keys.json` on your machine, which is git-ignored. `Twingate_Sandbox/` holds older and experimental code that is not part of the main app. This project is experimental, unsupported, and maintained by the V1rG0 Collective.
